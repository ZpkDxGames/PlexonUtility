# PlexonUtility 1.0.1-rc.2

Phase 3 consolidation release candidate. This prerelease supersedes the Phase 2 RC only because the accepted Phase 3 source now includes the approved bounded AFK runtime.

## Phase 3 delta

- Adds authoritative PlexonUtility AFK state and `/afk` self-toggle.
- Adds bounded automatic AFK timeout using one shared scheduler.
- Adds low-cost activity tracking and block-coordinate movement filtering.
- Adds `%plexonutility_afk%` and `%plexonutility_is_afk%` PlaceholderAPI output.
- Adds `PlexonUtilityAPI#isAfk(UUID)` read contract.
- Keeps PlexonUtility ownership intentionally narrow: feed/heal/enderchest/workbench plus AFK.

## Compatibility and boundaries

- Java 25 / class major 69.
- Paper API `26.2.build.121-stable`.
- PlexonCore `2.0.0` remains a provided runtime dependency and is not shaded.
- No Essentials clone is introduced.
- No production configuration is changed by this release.
- Essentials/GUIPlus/SetHome remain installed until the separate production cutover is explicitly approved.
