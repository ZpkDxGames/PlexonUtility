# PlexonUtility 3.0.0

PlexonUtility 3.0 is the stable interoperability and UI refinement release for PlexonCraft.

## Highlights

- Redesigned `/utility` into a richer 4-row Plexon hub with live AFK/player status, permission-aware utility actions, family integration status, refresh/close controls, and admin diagnostics.
- Added a PlexonHomes entry in the Utility hub. PlexonHomes remains the authoritative home/data/teleport service; PlexonUtility only surfaces its `/homes` GUI when the integration is ready.
- Formalized the existing homes slot contract for rank systems: `plexonhomes.limit.<N>` with highest effective numeric permission winning, plus `plexonhomes.limit.unlimited`.
- Added lifecycle-driven PlexonFamily discovery through `PlexonCore.integrations()` and `/utilityadmin family`.
- Added `AfkStateChangeEvent` so family plugins can react to AFK transitions without polling or duplicating AFK detection.
- Kept `%plexonutility_afk%` and `%plexonutility_is_afk%` for PlaceholderAPI/TAB integrations.
- Fixed message-catalog upgrades so missing keys from older `messages.yml` files are copied from bundled defaults and persisted without overwriting existing customization.
- Reduced repeated MiniMessage parsing by caching static rendered messages until reload; dynamic values continue to use safe component insertion.
- Updated the compile/runtime boundary to stable PlexonCore 2.0.5 and adopted owner-aware Core module lifecycle operations.
