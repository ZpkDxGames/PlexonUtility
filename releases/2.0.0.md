# PlexonUtility 2.0.0

PlexonUtility 2.0 is the stable Core-native utility refresh for PlexonCraft.

## Highlights

- New `/utility` hub using the shared PlexonCore GUI runtime.
- New `/trash` disposable inventory for quick item cleanup.
- Shared PlexonCore MiniMessage rendering with the PlexonUtility green→cyan visual identity.
- AFK async handoff moved onto the shared Core scheduler while retaining one bounded shared timeout scan.
- Expanded Core module capabilities and diagnostics.
- New external-complement visibility for land protection, rollback logging, permissions, custom menus, anti-cheat, display/HUD, profiling/pre-generation and proximity voice.
- Complement states are published into `PlexonCore.integrations()` instead of living in a disconnected private status table.

## Existing utilities retained

- `/feed [player]`
- `/heal [player]`
- `/enderchest [player]` / `/ec`
- `/workbench`
- `/afk`
- PlaceholderAPI AFK placeholders
- strict configuration validation
- atomic config/message reload
- exact target lookup and bounded in-memory cooldowns

## Specialist systems remain specialist

This release does not embed or replace GriefPrevention/Lands/Towny/WorldGuard, CoreProtect, LuckPerms, DeluxeMenus/ChestCommands, GrimAC/Vulcan, TAB/hologram plugins, spark/Chunky, or Simple Voice Chat. PlexonUtility detects these categories for administrative visibility while preserving clean product ownership.

## Runtime contract

- Java 25
- Paper 26.2
- PlexonCore 2.0.0 required
- PlaceholderAPI optional
- no plugin-owned database
- no shaded Core/Paper/Bukkit/PlaceholderAPI/Adventure runtime classes

## Release artifacts

The stable release workflow publishes:

- `PlexonUtility-2.0.0.jar`
- `SHA256SUMS.txt`
- `TEST_SUMMARY.txt`
- `PROVENANCE.txt`

The release workflow rebuilds and verifies the exact `main` commit before creating tag `v2.0.0` and the GitHub stable release.
