# PlexonUtility 3.4.0

PlexonUtility 3.4.0 upgrades `/invsee` from snapshot-only inspection to a permission-separated live inventory editor while preserving the rest of the 3.3 admin toolkit unchanged.

## Editable `/invsee`

- `plexonutility.admin.invsee` still grants view access.
- New `plexonutility.admin.invsee.edit` grants live mutation access.
- `plexonutility.admin` includes the new edit permission for full administrators.
- Storage slots 0–35, armor slots 45–48, and offhand slot 50 are editable.
- Left-click swaps a full cursor/target stack.
- Right-click splits from the target, places one item, stacks one compatible item, or safely swaps incompatible stacks.
- A refresh control reloads the displayed mirror from the target's live inventory.
- Every accepted mutation writes immediately to the live `PlayerInventory`; there is no close-time bulk commit.
- Target disconnects close all affected editor sessions safely.
- Multiple staff views are refreshed after each accepted admin edit.
- Inventory edits are written to the server log with actor, target, slot, before, and after summaries.

## Safety boundary

To prevent vanilla transfer mechanics from mutating the mirror without a corresponding authoritative target write, target-pane drag, shift-transfer, double-click collection, number-key/offhand swaps, drop gestures, and other unsupported top-pane click modes are cancelled. Staff can still move items through the normal cursor using the supported left/right interactions.

Read-only viewers retain the previous safe behavior and cannot mutate the target inventory.
