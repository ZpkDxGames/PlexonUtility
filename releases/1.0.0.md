# PlexonUtility 1.0.0

Initial Core-native utility extraction for PlexonCraft.

## Included

- `/feed [player]` with safe food/saturation clamping, optional monotonic cooldown, and explicit others/bypass permissions.
- `/heal [player]` using the player's actual max-health attribute, fire clearing, optional configured negative-effect clearing, optional monotonic cooldown, and explicit others/bypass permissions.
- `/enderchest` / `/ec` for the player's real Ender Chest plus online-only elevated targeting.
- `/workbench` for a virtual crafting table.
- `PlexonUtilityAPI` service exposing version and enabled-feature state.
- PlexonCore 2.0 module registration with narrow capabilities.
- `/utilityadmin diagnostics` and `/utilityadmin reload`.
- No database, no per-player repeating tasks, and no AFK engine in 1.0.0.

## Deliberately not included

Homes, spawn/hub/back/warps/TPA, chat, messaging, ranks, economy, jobs, skills, kits, mail, vanish, moderation, repair gameplay, flight, god mode, nicknames, and other Essentials-sized responsibilities remain owned by dedicated modules/providers.

AFK is deferred because no production consumer/dependency evidence was available during this repository-only implementation.

## Essentials decommission status

**BLOCKED / NOT PERFORMED by this release.**

PlexonUtility replaces only the selected convenience commands. Before removing Essentials from production, audit the actual server for remaining command ownership, Vault economy provider/balance storage, hard dependencies, kits/mail/nickname data, and other used Essentials features. Keep the existing Essentials JAR/configuration as rollback material until that audit and staging boot are complete.
