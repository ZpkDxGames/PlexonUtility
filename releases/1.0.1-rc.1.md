# PlexonUtility 1.0.1-rc.1

Phase 2 product-decision and correctness-hardening release candidate.

## Product decision

PlexonUtility is **ACTIVATED** as a deliberately narrow utility product. Its ownership remains limited to `/feed`, `/heal`, `/enderchest`, `/workbench`, and the small admin diagnostics/reload surface.

Dedicated Plexon products remain authoritative for travel, homes, repair/enchant/combine, shops, jobs, skills, Legendary Tools, claims, ranks, chat, server control, and shared runtime infrastructure.

## Hardening

- strict config types and bounded numeric validation;
- transactional config/messages candidate parsing before live swap;
- migration-safe message catalogs: an existing `1.0.0` file inherits newly introduced bundled keys without overwriting customized values;
- dead/invalid-player and invalid max-health protection for `/heal`;
- exact named-player lookup for target forms;
- deterministic surplus-argument rejection;
- explicit `plexonutility.reload` permission;
- removed the old no-op `migration.claim-standard-commands` configuration flag;
- expanded command/config/message/cooldown regression tests;
- dynamic version-aware distribution verification;
- Java 25 / class major 69 verification;
- non-shading checks for PlexonCore, PlaceholderAPI, Paper/Bukkit, and Adventure runtime classes.

## Deliberately not included

AFK, `/anvil`, `/hat`, `/trash`, `/repair`, homes, spawn/hub/back/warps, economy, kits, ranks, chat, vanish, moderation, teleport requests, or broad inventory administration.
