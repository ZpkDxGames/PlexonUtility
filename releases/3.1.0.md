# PlexonUtility 3.1.0

PlexonUtility 3.1 is the quiet-feedback and AFK presentation release for PlexonCraft.

## Highlights

- Added a centralized `FeedbackService` so routine utility feedback uses the appropriate HUD/chat surface instead of flooding chat.
- AFK entry now gives the affected player a persistent bossbar rather than a prefixed self-chat line.
- AFK exit removes the bossbar and uses a short actionbar confirmation.
- AFK social announcements are compact, prefixless by default, and exclude the player whose state changed.
- Added short-cycle suppression so rapid AFK toggles do not repeatedly announce `is back` to the server.
- Successful self `/feed`, `/heal`, and `/trash` feedback now uses actionbar by default.
- Errors, permission failures, cooldowns, and admin diagnostics continue to use normal chat where detail is appropriate.
- Added configuration for bossbar enablement/color/overlay, return actionbar, social-event prefixing, routine-success actionbars, and AFK short-return suppression.
- Prefixless HUD/social components are cached separately while dynamic values continue to use safe `PlexonCore.text().renderTemplate(...)` insertion.
- Bossbar state is reconciled and cleaned up on active transition, quit, reload, AFK feature disable, and plugin shutdown.
- Published the `quiet-feedback` capability through the PlexonCore module registry.

## Existing 3.x integration retained

- `/utility` Plexon hub with PlexonFamily status and PlexonHomes navigation.
- `%plexonutility_afk%` and `%plexonutility_is_afk%` PlaceholderAPI outputs for TAB and other display systems.
- `AfkStateChangeEvent` for push-based family interoperability.
- PlexonHomes rank-limit contract: `plexonhomes.limit.<N>` and `plexonhomes.limit.unlimited`.
- Message-catalog migration for newly introduced `messages.yml` keys without overwriting customized values.
- PlexonCore 2.0.5 shared text, GUI, scheduler, module, and integration services.

## Performance and lifecycle guarantees

- no feedback polling task;
- no per-player repeating scheduler;
- one shared AFK timeout scan only when automatic AFK is enabled;
- no plugin-local MiniMessage parser;
- no gameplay-thread file/database/network I/O;
- deterministic bossbar cleanup and replacement.

## Distribution guarantees

The stable workflow rebuilds the exact merged `main` source, runs the complete Maven test suite, verifies Java 25 class major 69, Paper 26.2 metadata, the quiet-feedback runtime class, required commands/resources, no provided-API shading, and publishes checksum/test/provenance evidence alongside the JAR.
